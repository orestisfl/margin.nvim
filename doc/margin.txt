1. INTRODUCTION                                            *margin-introduction*

margin.nvim adds local review comments to any Neovim buffer. It shows each
comment below its selected lines.

The plugin does not create diff views or change buffer text. It adds extmarks,
signs, and virtual lines to existing buffers.

==============================================================================
2. REQUIREMENTS                                            *margin-requirements*

- Neovim 0.12 or newer.
- No runtime dependencies.

==============================================================================
3. SETUP                                                          *margin-setup*

|setup()| is optional. All commands use default values before setup. >lua

    require('margin').setup({
      inline = true,
      max_width = 80,
      context_lines = 3,
      sign_text = '┃',
      data_dir = nil,
    })
<
Install the plugin with lazy.nvim: >lua

    { 'orestisfl/margin.nvim', opts = {} }
<
You can load margin.nvim from a <Plug> mapping or a |:Margin| command. The
plugin restores comments in buffers that are already open. >lua

    {
      'orestisfl/margin.nvim',
      keys = {
        { '<leader>mc', '<Plug>(margin-comment)', mode = { 'n', 'x' } },
        { ']m', '<Plug>(margin-next)' },
        { '[m', '<Plug>(margin-prev)' },
      },
      cmd = 'Margin',
      opts = {},
    }
<
To show saved comments before you use a mapping, load the plugin when Neovim
reads a buffer: >lua

    {
      'orestisfl/margin.nvim',
      event = { 'BufReadPost', 'BufWinEnter' },
      opts = {},
    }
<
==============================================================================
4. COMMANDS                                                    *margin-commands*

                                                                      *:Margin*
:Margin comment         Add a comment to the current line or range.
:Margin edit            Edit the comment at the cursor.
:Margin delete          Delete the comment at the cursor.
:Margin[!] list         Open comments in the quickfix list. `!` includes
                        archived comments.
:Margin[!] export [path]
                        Export comments to a split or a file. `!` includes
                        archived comments and does not archive them.
:Margin archive         Archive the comment at the cursor.
:Margin unarchive       Unarchive the comment at the cursor.
:Margin archived        Show or hide archived comments.
:Margin inline          Show or hide inline comment boxes.
:Margin clear           Delete all comments after confirmation.

Cursor commands use the smallest comment range that contains the cursor line.

==============================================================================
5. MAPPINGS                                                    *margin-mappings*

The plugin does not create default mappings. It provides these <Plug>
mappings: >

    <Plug>(margin-comment)   n and x mode
    <Plug>(margin-edit)
    <Plug>(margin-delete)
    <Plug>(margin-list)
    <Plug>(margin-export)
    <Plug>(margin-archive)   archive comment at cursor
    <Plug>(margin-unarchive)
    <Plug>(margin-archived)  show or hide archived comments
    <Plug>(margin-next)      go to next comment in buffer
    <Plug>(margin-prev)
<
Suggested bindings: >lua

    local map = vim.keymap.set
    map({ 'n', 'x' }, '<leader>mc', '<Plug>(margin-comment)')
    map('n', '<leader>me', '<Plug>(margin-edit)')
    map('n', '<leader>md', '<Plug>(margin-delete)')
    map('n', '<leader>ml', '<Plug>(margin-list)')
    map('n', '<leader>mx', '<Plug>(margin-export)')
    map('n', ']m', '<Plug>(margin-next)')
    map('n', '[m', '<Plug>(margin-prev)')
<
COMMENT WINDOW                                                 *margin-composer*

The comment window uses the `markdown` file type. It accepts multiple lines.

Use `:w` or <C-s> to save the comment. If the comment is empty, use `q` to
cancel. If the comment contains text, `q` asks whether to save it.

Empty text does not create or change a comment. margin.nvim removes blank lines
from the end of saved comments.

==============================================================================
6. CONFIGURATION                                                 *margin-config*

                                                              *margin.Config*
inline          (boolean, default true)
                Show comment boxes with |virt_lines|. When false, only signs
                identify comments.

show_archived   (boolean, default false)
                Show archived comments with dim text and an `(archived)` tag.
                See |margin-archive|.

max_width       (integer, default 80)
                Maximum width of comment-box text.

context_lines   (integer, default 3)
                Number of context lines in snippets and diff hunks.

sign_text       (string, default '┃')
                Text in the sign column for comments.

data_dir        (string|nil, default nil)
                Session directory. The default is `stdpath('data')/margin`.

HIGHLIGHTS                                                   *margin-highlights*

The plugin defines these groups with `default = true`: >

    MarginSign     -> DiagnosticSignInfo
    MarginComment  -> Comment
    MarginBorder   -> FloatBorder
    MarginOrphan   -> DiagnosticWarn
    MarginArchived -> NonText
<
==============================================================================
7. EXPORT FORMAT                                                 *margin-export*

`:Margin export` writes one `## path:line` section for each comment. Each
section contains the comment and its code context.

In a diff window, the context is the related unified-diff hunk. In other
buffers, the context contains the selected lines and nearby lines.

An old-side header includes ` (old version)`. An orphaned comment includes
`(position can be stale)`.

Without a path, the Markdown opens in a `margin://export` split. You can edit,
yank, or save the export. A new export replaces the split contents.

`require('margin').export()` returns the Markdown string.

                                                              *margin-archive*
Archived comments do not appear in normal lists or exports. They keep their
positions and move when the related text moves.

A file export asks about archiving after it writes the file. A split export
asks when the split closes.

`:Margin archived` shows archived comments with dim text and an `(archived)`
tag. Use `:Margin unarchive` to make the selected comment active.

Add `!` to list or export archived comments. These commands do not change the
archive state.

==============================================================================
8. DIFF ALIGNMENT                                             *margin-alignment*

In a two-window diff, margin.nvim adds blank lines below the related line in
the other buffer. These lines keep both buffers aligned.

For a diff with more than two windows, margin.nvim uses the first related
window.

==============================================================================
9. PERSISTENCE                                               *margin-persistence*

margin.nvim finds the project root from a `.git` marker. If no marker exists,
it uses the working directory.

The plugin stores one JSON session file for each project root. The `data_dir`
value in |margin-config| selects the session directory.

When a buffer loads, margin.nvim finds the saved text at its old line. If the
text moved, it searches 40 lines in each direction.

If one line matches, the comment moves to that line. If no unique line matches,
the plugin marks the comment as orphaned and keeps it.

==============================================================================
10. HEALTH                                                       *margin-health*

Run `:checkhealth margin`. The report contains the Neovim version, the session
directory, and the number of stored sessions.
